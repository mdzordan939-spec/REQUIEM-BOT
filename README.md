# REQUIEM BOT starter
Initial Telegram bot + minimal black/red Mini App UI.

1. Install Python 3.12+.
2. Copy `.env.example` to `.env`, add bot token and public HTTPS Mini App URL.
3. From project folder run `python -m venv .venv`.
4. Windows PowerShell: `.venv\Scripts\Activate.ps1`
5. Install: `pip install -r requirements.txt`
6. Start: `python bot/main.py`

Mini App requires public HTTPS hosting of the `webapp` directory. Do not share or commit `.env` or the bot token.
